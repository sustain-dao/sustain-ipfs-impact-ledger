# Evidence Placeholder — OSCI Example

This folder contains illustrative placeholder evidence files used to demonstrate
the OSCI evidence bundle structure.

The files in this directory do not represent finalized, audited, or verified
real-world evidence. They are provided for demonstration purposes only.

In a production deployment, this folder would contain:
- Satellite imagery
- Field photographs
- Official reports (PDF)
- Third-party attestations

All evidence would be referenced and hashed via metadata.json.
