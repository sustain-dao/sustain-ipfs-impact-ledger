# Patagonia Wildfire Evidence — OSCI Example

This folder contains a sample Open Sustainability Commitments on IPFS (OSCI) evidence bundle.

The purpose of this example is to demonstrate how climate impact evidence can be packaged with standardized metadata and prepared for IPFS and optional Filecoin persistence.

This example references wildfire-affected regions in Patagonia as an early real-world context for validating the OSCI data model.

## Contents

- metadata.json — structured metadata describing the evidence bundle
- evidence/ — supporting documents (images, PDFs, reports)

This example is provided for demonstration purposes only and does not represent a finalized or audited dataset.
